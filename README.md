# PELICAN // ON A BIKE · 鹈鹕骑自行车

一个纯程序化生成的实时 3D 网页：一只鹈鹕骑着自行车穿过城市街道。

## 特点

- **零外部资源**：鹈鹕、自行车、街道、天空、所有贴图与音效全部由 JavaScript 在运行时生成，
  仓库里只有一个 HTML、一个 three.js 引擎文件（MIT）和一张自动生成的封面图。
- **程序化鹈鹕**：躯干/头部用变形球体，脖子是每帧重建顶点的锥形管（转头时脖子跟着弯），
  喉囊是参数曲面生成的水滴形气囊，喙是沿曲线放样的锥管。
- **两段 IK 踩踏**：大腿/小腿用两连杆逆运动学实时解算，踝关节球体 + 三趾蹼足稳稳踩在脚踏上。
- **物理联动**：踏频由真实齿比换算（轮速 = 踏频 × 2.3），车轮、曲柄、链条贴图同步；
  车把反向转向、身体起伏、喉囊弹簧、围巾跟随链都跟着速度变化。
- **昼夜循环**：10 个关键帧插值驱动太阳角度、天空渐变、雾色、曝光、路灯与大楼窗光。
- **程序化音频**：WebAudio 合成车铃（4 个泛音）、轮胎滚动噪声、风声、喇叭，无音频文件。
- **5 个机位**：环绕 / 追踪 / 电影 / 鸟喙第一视角 / 车轮特写。

## 本地运行

需要通过 HTTP 访问（ES module 不能用 file:// 打开）：

```bash
python -m http.server 8123
# 打开 http://127.0.0.1:8123/
```
